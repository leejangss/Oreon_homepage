OREON NEWS 모바일 적용 순서

1. GitHub Oreon_homepage 저장소의 widgets/news 폴더에 아래 2개 파일을 업로드 후 커밋합니다.
   OREON_News_Mobile_Hero_V1.html
   OREON_NEWS_MOBILE_CARD_V1.js
   기존 PC 파일은 지우거나 바꾸지 않습니다.

2. GitHub Pages 배포 완료 후 진행합니다.

3. 아임웹 모바일 디자인 모드에서 모바일 전용 히어로 코드위젯 내용을
   01_MOBILE_HERO_WIDGET.txt 전체 내용으로 교체합니다.
   기존 PC 히어로는 모바일에서 숨김을 유지합니다.
   모바일 히어로 섹션의 배경은 #000107, 상하/좌우 여백은 0으로 설정합니다.

4. 기존 아임웹 게시판은 그대로 사용합니다. 새 게시판을 만들지 않습니다.
   게시판 목록 설정에서 한 페이지 표시 수가 6개인지 확인합니다.
   현재 공개 목록에서 6개를 확인했지만 전체 표시 수 설정값은 직접 확인이 필요합니다.
   PC와 모바일이 같은 게시판 설정을 공유하는 경우 표시 수 변경은 PC에도 반영될 수 있습니다.

5. 게시판 아래 기존 JS 코드위젯의 내용을 지우고
   02_BOARD_JS_WIDGET.txt의 두 줄을 함께 붙입니다.
   이 위젯은 모바일에서도 실행되어야 합니다.
   동일 PC 스크립트를 다른 위젯에 중복해서 추가하지 않습니다.
   모바일 JS는 767px 이하에서만 디자인을 변경합니다.

6. 아임웹 미리보기에서 확인한 뒤 게시합니다.
   - 히어로 NEWS 원형 문구 8회
   - 사진 16:9 중앙 크롭, 다크 카드, 흰 제목
   - 한 줄에 1개, 한 페이지 6개 (원본 게시판 목록 설정 기준)
   - Read more 상세글 이동 및 원본 페이지 번호
   - PC 디자인 유지

안내:
미리보기용 6개 카드가 고정으로 들어있는 HTML은 설치에 사용하지 않습니다.
실제 이미지와 제목은 기존 아임웹 게시판에서 읽습니다.
현재 목록에 요약문이 비어 있어 요약문은 생성하지 않습니다.
페이지 번호는 기존 아임웹 페이지네이션을 유지합니다.
실제 아임웹 관리자 미리보기에서의 작동 검증은 아직 하지 않았습니다.
